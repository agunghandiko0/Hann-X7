# HANN X7 - Advanced Multi-Bot & Warming Manager (v8.4.0-PREMIUM)

[![Version](https://img.shields.io/badge/Version-8.4.0--PREMIUM-cyan.svg)](#)
[![Platform](https://img.shields.io/badge/Platform-Android%20|%20PC%20|%20VPS-blue.svg)](#)

HANN X7 adalah solusi manajemen dan pemanasan akun WhatsApp tingkat lanjut yang ditenagai oleh kecerdasan buatan (AI) lokal. Dirancang secara presisi untuk membangun reputasi akun secara organik melalui simulasi interaksi manusia yang natural guna meminimalisir risiko blokir pada aktivitas *farming* maupun *broadcasting*.

---

## 🛠️ Fitur Unggulan

* 🤖 **AI Nonstop Anti-Limit:** Interaksi cerdas yang berjalan terus-menerus tanpa batasan kuota untuk memastikan aktivitas akun tetap konsisten.
* 🔥 **Multi-Session Cross-Chat:** Simulasi pemanasan otomatis melalui percakapan silang antar banyak sesi/kloningan akun secara simultan.
* 🎯 **Targeted Group Warming:** Kemampuan untuk memfokuskan aktivitas interaksi pada ID grup spesifik sesuai konfigurasi pengguna.
* 🌙 **Smart Sleep Scheduler:** Manajemen waktu istirahat bot otomatis untuk menjaga profil aktivitas akun tetap organik dan menyerupai perilaku manusia.
* 🎭 **Advanced AI Persona:** Kustomisasi karakter balasan AI yang tersedia dalam 3 mode utama: **Normal (Casual)**, **Bisnis (CS)**, dan **Formal (Professional)**.
* ⚙️ **Granular Interaction Rules:** Kontrol mandiri (ON/OFF) untuk izin respons otomatis pada kategori Pesan Pribadi (PC), Grup, maupun pemantauan Status.
* 💻 **Multi-Platform Support:** Optimal untuk dijalankan pada lingkungan **Android (Termux)**, **PC (Windows/Linux/macOS)**, maupun **VPS**.

## 🚀 Instalasi Sistem

Pastikan perangkat Anda telah terpasang **Node.js** versi terbaru.

```bash
# Clone repositori
git clone [https://github.com/agunghandiko0/Hann-X7.git](https://github.com/agunghandiko0/Hann-X7.git)

# Masuk ke direktori proyek
cd Hann-X7

# Instalasi dependensi
npm install

# Menjalankan aplikasi
node app.js
